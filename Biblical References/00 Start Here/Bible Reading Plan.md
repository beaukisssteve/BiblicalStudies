# Bible Reading Plan

**Goal:** Read the entire Bible in one year and add observations to linked notes as you go.

## Suggested rhythm
- Read 3–4 chapters daily on average (1,189 chapters / 365 days ≈ 3.26).
- Add one or two key observations to each chapter note.
- Create reference notes only for subjects you want to revisit.
- Reserve one weekly review period to verify citations and expand links.

This is a flexible framework, not a dated schedule. You can later add a chronological or canonical calendar.
